Character & motion

Neutral, attentive cat. No default grin, sad mouth, or mood meter. Character art is separate from status icons and touch behavior.

Playback rules

  • Fixed 32 × 32 grid. Same origin and baseline in every frame. Integer scaling, nearest-neighbor. No stretch, bounce, fade, or live shadow.
  • State wins immediately. Cancel old frame timers on each state change. Never finish a blink before showing listening.
  • Motion is not status. Keep microphone / thinking / speaker indicator outside the sprite. No fake audio waveform or claimed lip-sync.
  • Reduced Motion: use each state’s final pose; speaking keeps mouth open. No blink or loop.
  • Bounded redraw: change frames only when scheduled. Redraw affected sprite bounds, not the whole screen. Hardware cost still needs measurement.

Use Character state and Character motion in Tweaks. This isolated preview and Cube use the same frames and timing.

Other Cube states

Setup: QR, no cat. Pairing and volume: ready pose, still. Charging: ready behavior. Wi-Fi, gateway, or account failure: unavailable pose plus a distinct status cue. During speech, active voice pose overrides low-battery pose; battery warning stays separate.

Assets: prototype/assets/cat-<frame>.svg. Names beneath frames match filenames. These are browser references for raster export—not a request for an SVG renderer on ESP32.

Built for restraint

Original pixel cat, inspired by handheld virtual pets and early creature-game sprites. Small 32 × 32 frame set; one entry blink and a two-frame speaking loop. No feeding, mood scores, or games. Expressions follow explicit device state, never an inferred emotion. No live blur, vector avatar renderer, waveform, or idle animation loop. App identity remains unchanged. SVG files are browser references; firmware would use raster sprites, not a live SVG renderer.

Corner mask shown is provisional and deliberately conservative. All essential content sits within central 352 × 352 px. Screen-off behavior is a proposal, not a claim about deeper sleep or battery savings.

Technical notes specify an on-screen setup code. Preview code contains only “sentient:preview”, not credentials. Final QR density and scan distance must be checked with the actual enrollment payload. Personalization and wallpapers remain future work; no launch settings added.

Hardware basis: Waveshare board reference · LVGL partial redraw · ESP32-S3 memory limits. RGB565 raw pixels: 128 × 128 = 32 KiB; 480 × 480 = 450 KiB. These are size calculations, not measured performance.
