# Code of conduct

Sentient is a personal project shared in public. Participation should make the
project safer, clearer, and easier to maintain.

## Expected behavior

- Be respectful and constructive.
- Critique ideas and code, not people.
- Respect privacy. Do not post credentials, household information, prompts,
  transcripts, raw audio, or other personal data.
- Disclose security concerns privately according to [`SECURITY.md`](SECURITY.md).
- Accept maintainer decisions about scope and project direction.

Harassment, threats, discrimination, deliberate disruption, impersonation, and
publication of another person's private information are not acceptable.

## Enforcement

The maintainer may edit or remove contributions, comments, issues, or other
participation that violates these expectations, and may temporarily or
permanently restrict participation.

Report ordinary conduct concerns to the repository owner through the contact
information on their GitHub profile. If a report contains sensitive or private
information, use GitHub's private
[Report a vulnerability](https://github.com/dev32-io/sentient/security/advisories/new)
form and identify it as a conduct report.
