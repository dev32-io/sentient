# Phase 3.5: Voice WebSocket Wiring — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Phase 3 voice gap. Wire the client's toggle-to-talk button through the gateway's WebSocket into Deepgram STT → OpenRouter LLM → Fish Audio TTS, and back to the client's AudioWorklet playback. After this phase, clicking the mic, speaking, and clicking again produces an audible assistant response without any browser or gateway errors.

**Architecture:** Replace the client's `MediaRecorder`-based WebM/Opus capture with an `AudioWorkletNode` that emits raw 16-bit PCM chunks over the existing binary WebSocket channel. On the gateway, a per-session voice-turn handler connects Deepgram once, reuses the connection across turns, and uses a per-turn `AbortController` to cancel STT/LLM/TTS on `barge_in` or session close. TTS output is configured to emit PCM (not Opus) so the client can decode with a trivial Int16→Float32 conversion in the existing `handleBinaryMessage`, feeding the already-wired `AudioWorkletNode` playback ring buffer.

**Tech Stack:** Bun 1.3+, TypeScript 5.8+ (strict), Vitest, Preact 10, Vite 6, `@preact/signals`, `@sentient/protocol`. Providers: Deepgram Nova-3 (STT, linear16 @ 48kHz), OpenRouter (LLM streaming), Fish Audio (TTS, PCM @ 48kHz).

**Sample rate decision:** 48kHz PCM16 on the wire in both directions. This matches `AudioContext.sampleRate` defaults on modern browsers, avoids downsampling on the client, and Deepgram's `linear16` accepts it. Fish Audio TTS also supports PCM @ 48kHz via the existing `TTSConfig.sampleRate` field.

**Builds on:** Phase 3 (merge commit `b1567a5` on `develop`). Assumes `develop` has the Phase 3 web client + gateway static serving.

**Prerequisites:** `OPENROUTER_API_KEY`, `DEEPGRAM_API_KEY`, `FISH_AUDIO_API_KEY`, `FISH_AUDIO_VOICE_ID` must be set in `gateway/.env` for end-to-end smoke tests. Unit tests mock all providers and don't need real keys.

// gateway/src/pipeline/voice-turn.ts
import type { ContextAssembler, ConversationTurn } from "../context/context-assembler.ts";
import type { LLMProvider } from "../providers/llm-provider.ts";
import { createStreamingOverlap } from "./processors/streaming-overlap.ts";
import type { TTSProcessor } from "./processors/tts-processor.ts";

export interface VoiceTurnOptions {
  transcript: string;
  history: ConversationTurn[];
  contextAssembler: ContextAssembler;
  llmProvider: LLMProvider;
  ttsProcessor: TTSProcessor;
  chatModel: string;
  signal: AbortSignal;
}

export type VoiceTurnEvent =
  | { type: "text.delta"; payload: string }
  | { type: "text.done"; payload: string }
  | { type: "audio.start"; payload: null }
  | { type: "audio.frame"; payload: Uint8Array }
  | { type: "audio.done"; payload: null };

export async function* runVoiceTurn(options: VoiceTurnOptions): AsyncGenerator<VoiceTurnEvent> {
  const { transcript, history, contextAssembler, llmProvider, ttsProcessor, chatModel, signal } = options;

  const messages = contextAssembler.buildMessages(history, transcript);
  let fullText = "";
  let audioStartObserved = false;
  let audioStartEmitted = false;

  // Tee the LLM stream: one path yields text deltas, the other feeds the sentence aggregator.
  const textBuffer: string[] = [];
  async function* llmTap(): AsyncGenerator<string> {
    for await (const token of llmProvider.stream({ model: chatModel, messages, signal })) {
      textBuffer.push(token);
      yield token;
    }
  }

  const overlap = createStreamingOverlap(ttsProcessor);
  overlap.onAudioStart(() => {
    audioStartObserved = true;
  });

  // Merge text deltas with audio frames using a queue-and-poll pattern. Since the
  // overlap generator consumes llmTokens internally, we observe tokens via the
  // shared textBuffer and drain them between audio frame yields. The audio.start
  // event is emitted inline the first time we observe the overlap's onAudioStart
  // callback firing, just before the first audio.frame.
  let textIndex = 0;
  for await (const frame of overlap.process(llmTap(), signal)) {
    // Drain any text tokens that arrived since last yield.
    while (textIndex < textBuffer.length) {
      const token = textBuffer[textIndex++];
      if (token === undefined) continue;
      fullText += token;
      yield { type: "text.delta", payload: token };
    }

    // Emit audio.start exactly once, just before the first audio.frame.
    if (audioStartObserved && !audioStartEmitted) {
      yield { type: "audio.start", payload: null };
      audioStartEmitted = true;
    }

    yield { type: "audio.frame", payload: frame.data };
  }

  // Flush any trailing text tokens that arrived after the final audio frame.
  while (textIndex < textBuffer.length) {
    const token = textBuffer[textIndex++];
    if (token === undefined) continue;
    fullText += token;
    yield { type: "text.delta", payload: token };
  }

  yield { type: "text.done", payload: fullText };
  if (audioStartEmitted) {
    yield { type: "audio.done", payload: null };
  }
}
```

**Note on the tee pattern:** `createStreamingOverlap` from Phase 2 consumes the LLM generator internally to feed its sentence aggregator. We can't `yield` text deltas from inside that consumer, so we observe them via a shared buffer (`textBuffer`) that the `llmTap` generator appends to as tokens flow through. The outer loop drains the buffer between audio frame yields. This gives us interleaved `text.delta` → `text.delta` → `audio.frame` → `text.delta` → `audio.frame` ordering that naturally matches the streaming-overlap design.

// gateway/src/pipeline/voice-session.ts
import type { STTConfig, STTProvider } from "../providers/stt/stt-types.ts";

export interface VoiceSessionOptions {
  sttProvider: STTProvider;
  sttConfig: STTConfig;
}

export interface VoiceSession {
  /** Connect STT if not already connected. Idempotent. */
  startRecording(): Promise<void>;
  /** True after at least one successful startRecording. */
  isSTTConnected(): boolean;
  /** Forward an audio chunk to STT. No-op if not connected. */
  sendAudio(audio: Uint8Array): void;
  /** Begin a new turn — returns an AbortController the caller owns and passes to runVoiceTurn. */
  beginTurn(): AbortController;
  /** Abort the current turn's controller (if any). Does not disconnect STT. */
  bargeIn(): void;
  /** Final cleanup — disconnect STT and abort any outstanding turn. */
  close(): Promise<void>;
}

export function createVoiceSession(options: VoiceSessionOptions): VoiceSession {
  const { sttProvider, sttConfig } = options;
  let sttConnected = false;
  let sttConnectController: AbortController | null = null;
  let activeTurnController: AbortController | null = null;

  async function startRecording(): Promise<void> {
    if (sttConnected) return;
    sttConnectController = new AbortController();
    await sttProvider.connect(sttConfig, sttConnectController.signal);
    sttConnected = true;
  }

  function isSTTConnected(): boolean {
    return sttConnected;
  }

  function sendAudio(audio: Uint8Array): void {
    if (!sttConnected) return;
    sttProvider.sendAudio(audio);
  }

  function beginTurn(): AbortController {
    if (activeTurnController && !activeTurnController.signal.aborted) {
      activeTurnController.abort();
    }
    activeTurnController = new AbortController();
    return activeTurnController;
  }

  function bargeIn(): void {
    activeTurnController?.abort();
  }

  async function close(): Promise<void> {
    activeTurnController?.abort();
    activeTurnController = null;
    sttConnectController?.abort();
    if (sttConnected) {
      await sttProvider.disconnect();
      sttConnected = false;
    }
  }

  return { startRecording, isSTTConnected, sendAudio, beginTurn, bargeIn, close };
}
```

```typescript
// web/src/audio/capture-worklet.ts
/// <reference path="./audio-worklet.d.ts" />

/**
 * Capture processor: receives Float32 mic samples from the MediaStream source,
 * converts to Int16 PCM, and posts to the main thread as binary ArrayBuffers.
 *
 * Main thread → this worklet:
 *   (no messages expected)
 * This worklet → main thread:
 *   { type: "pcm", buffer: ArrayBuffer } — Int16 PCM chunk
 */

const FRAME_SIZE = 128; // AudioWorklet render quantum
const BATCH_FRAMES = 4; // 4 × 128 = 512 samples @ 48kHz ≈ 10.6ms

class CaptureProcessor extends AudioWorkletProcessor {
  private batchBuffer: Int16Array;
  private batchOffset: number;

  constructor() {
    super();
    this.batchBuffer = new Int16Array(FRAME_SIZE * BATCH_FRAMES);
    this.batchOffset = 0;
  }

  process(inputs: Float32Array[][]): boolean {
    const input = inputs[0]?.[0];
    if (!input) return true;

    for (let i = 0; i < input.length; i++) {
      // Clamp and convert Float32 [-1, 1] → Int16 [-32768, 32767].
      const sample = Math.max(-1, Math.min(1, input[i] ?? 0));
      this.batchBuffer[this.batchOffset++] = sample < 0 ? sample * 0x8000 : sample * 0x7fff;

      if (this.batchOffset >= this.batchBuffer.length) {
        // Copy into a fresh ArrayBuffer for transfer (neuters the shared one).
        const out = new Int16Array(this.batchBuffer.length);
        out.set(this.batchBuffer);
        this.port.postMessage({ type: "pcm", buffer: out.buffer }, [out.buffer]);
        this.batchOffset = 0;
      }
    }

    return true;
  }
}

registerProcessor("capture-processor", CaptureProcessor);
```

      source.connect(node);
      // Do NOT connect node → ctx.destination (we don't want mic playback feedback).

      talkState.value = "recording";
      onStarted();
    } catch (error: unknown) {
      talkState.value = "idle";
      onError(classifyGetUserMediaError(error));
      cleanupCapture();
    }
  }, [talkState, onAudioData, onStarted, onError, cleanupCapture]);

  const stopCapture = useCallback(() => {
    if (talkState.value !== "recording") return;
    cleanupCapture();
    talkState.value = "idle";
    onStopped();
  }, [talkState, cleanupCapture, onStopped]);

  return useMemo(
    () => ({ talkState, startCapture, stopCapture }),
    [talkState, startCapture, stopCapture],
  );
}

const handleBinaryMessage = useCallback(
  (data: ArrayBuffer) => {
    // Gateway sends PCM16 samples (Int16). Convert to Float32 for the
    // AudioWorklet playback buffer: divide by 32768 to map [-32768, 32767]
    // into [-1.0, 1.0).
    const int16 = new Int16Array(data);
    const float32 = new Float32Array(int16.length);
    for (let i = 0; i < int16.length; i++) {
      float32[i] = (int16[i] ?? 0) / 0x8000;
    }
    playback.enqueueSamples(float32);
  },
  [playback],
);
